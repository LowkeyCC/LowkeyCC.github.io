# Conseils pour les Revenants

## Votre objectif

Vous êtes Revenant (le Cercle). Vous devez **éliminer tous les Vivants** avant qu'ils ne vous éliminent tous. Vous connaissez les autres Revenants — mais les Vivants ne vous connaissent pas.

## Stratégies de base

### 1. Ne vous faites pas remarquer
Le meilleur Revenant est celui que personne ne soupçonne. Agissez normalement. Ne bluffez pas trop. Ne soyez pas trop calme ou trop nerveux.

### 2. Protégez les alliés
Si un autre Revenant est accusé, défendez-le (subtilement). Un Revenant accusé est un Revenant en danger.

### 3. Créez la confusion
Accusez des Vivants entre eux. Si deux Vivants s'accusent mutuellement, les Revenants peuvent frapper en silence.

### 4. Éliminez les investigateurs
Les masques informationnels (Medium, Oracle, Sans-Visage) sont vos ennemis prioritaires. Si le Medium examine un Revenant, le jeu est fini.

### 5. Utilisez les Duels à votre avantage
Un Duel est une occasion de tuer un Vivant. Mais attention : si vous perdez, votre identité est révélée.

## Erreurs à éviter

### Accuser un autre Revenant
C'est l'erreur fatale. Ne jamais accuser un allié.

### Être trop agressif
Un Revenant agressif est un Revenant suspect. Calmez-vous.

### Ignorer les Débats
Les Débats sont votre occasion de semer la confusion. Ne les négligez pas.

### Révéler votre camp
Ne dites jamais que vous êtes Revenant. Évidemment.

## Stratégies avancées

### Le parfait innocent
Jouez comme un Vivant parfait. Accusez d'autres joueurs (des Revenants, en privé). Créez l'illusion que vous êtes du bon côté.

### Le bouc émissaire
Si un Revenant est acculé, sacrifiez-le. Laissez-le mourir en laissant une rumeur fausse. Les Vivants vont croire ses derniers mots.

### Le piège vocal
Utilisez les zones vocales à votre avantage. Si un Vivant est isolé, c'est une cible facile pour le Poursuite ou le Sacrifice.

## Conseils par masque

### Si vous portez un masque informationnel
Vous êtes dans une position paradoxale : vos pouvoirs révèlent des informations, mais vous êtes Revenant. Utilisez-les pour orienter les investigations vers des Vivants.

### Si vous portez un masque offensif
Vous êtes l'assassin du Cercle. Frappez pendant la nuit. Utilisez vos dégâts pour éliminer les Vivants sans vous faire remarquer.

### Si vous portez un masque de support
Vous êtes le protecteur du Cercle. Soignez vos alliés Revenants. Maintenez-les en vie.
