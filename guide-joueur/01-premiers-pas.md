# 🎮 Premiers pas

## Vous êtes nouveau ?

Bienvenue au Carnaval ! Carnival of the Deads est un jeu de déduction sociale et de bluff joué sur Discord. Pas de panique — les règles sont simples une fois que vous avez compris le principe.

## Le principe en 3 points

1. **Vous portez un masque** qui vous donne des pouvoirs.
2. **Certains joueurs sont des Revenants** (le camp secret) — vous ne savez pas qui.
3. **Éliminez l'autre camp** pour gagner.

## Les phases de jeu

Une partie alterne entre 4 phases :

1. 🌙 **Nuit** : les joueurs utilisent leurs pouvoirs secrets en MP.
2. 📢 **Résolution** : le bot affiche les résultats (sans dire qui a fait quoi).
3. 💬 **Débats** : discussion libre (5 minutes). Vous pouvez vous déplacer entre les salons.
4. ☀️ **Actions de Jour** : les joueurs utilisent leurs pouvoirs publics.
5. ⚔️ **Duels** : les joueurs se défient en combat direct.

## Ce que vous devez savoir

### Vos PV sont secrets
Vous connaissez vos propres PV, mais pas ceux des autres. Seul le total de dégâts reçus est public.

### Les camps sont secrets
Vous ne savez pas qui est Revenant sauf si un pouvoir vous le révèle.

### Les masques se brisent
Quand un masque atteint 0 PV, le joueur est K.O. Son identité est révélée (pas son camp).

### Vous pouvez laisser une rumeur
Quand votre masque se brise, vous pouvez laisser un dernier message (200 caractères). C'est votre dernière chance d'influencer la partie.

## Conseils pour commencer

1. **Lisez le Grimoire des Masques** (envoyé en MP au début de la partie). C'est votre bible.
2. **Écoutez les discussions** pendant les Débats. Les indices sont partout.
3. **Ne accusez pas sans preuve** — les Reventants mentent aussi bien que les Vivants.
4. **Utilisez vos pouvoirs avec stratégie** — ne les gaspillez pas.
5. **Amusez-vous** — c'est un jeu. Le plus important, c'est de s'amuser.
