Conseils pour les Vivants ​

Votre objectif ​

Vous êtes Vivant. Vous devez éliminer tous les Revenants avant qu'ils ne vous éliminent tous. Vous ne savez pas qui sont les Revenants — c'est le défi.

Stratégies de base ​

1. Réseaux ​

Pendant les Débats, parlez aux autres joueurs. Créez des alliances. Les Vivants qui travaillent ensemble survivent plus longtemps.

2. Accusez sans preuve ​

Vous n'avez pas de preuve, mais les accusations créent de la panique. Un Revenant accusé va se défendre — et se défendre, c'est révéler des indices.

3. Écoutez les rumeurs ​

Quand un joueur meurt, sa rumeur peut contenir un indice. Un Vivant mort va probablement laisser un indice sur un Revenant. Un Revenant mort va probablement mentir.

4. Utilisez les masques informationnels ​

Si vous portez un masque avec des capacités d'information (Medium, Oracle, Sans-Visage), utilisez-les. Vous êtes les yeux des Vivants.

5. Protégez les alliés utiles ​

Si un joueur a un masque puissant (Medium, Oracle, Sans-Visage), protégez-le. Les Revenants vont le cibler en premier.

Erreurs à éviter ​

Accuser tout le monde ​

Si vous accusez tout le monde, personne ne vous croira. Concentrez-vous sur les suspects.

Ignorer les Débats ​

Les Débats sont votre principale source d'information. Ne les négligez pas.

Révéler votre camp ​

Ne dites jamais explicitement que vous êtes Vivant. Les Revenants vont vous cibler.

Jouer trop passivement ​

Un Vivant passif est un Vivant mort. Utilisez vos pouvoirs, participez aux Duels, agissez.

Stratégies avancées ​

Le piège ​

Accusez un joueur pour voir comment il réagit. Un Revenant va se défendre nerveusement. Un Vivant va se défendre calmement.

Le sacrifice ​

Si vous êtes un masque faible (10-12 PV), sacrificez-vous pour identifier un Revenant. Votre mort peut révéler des indices.

Le compteur ​

Mémorisez les PV des masques. Si un joueur a reçu beaucoup de dégâts, il est probablement à bout. Défiez-le en Duel.

Conseils par masque ​

Si vous portez le Medium ou l'Oracle ​

Vous êtes l'investigateur principal. Examinez les joueurs suspects chaque nuit (Medium) ou défiez-les en Duel pour connaître leur camp (Oracle). Votre information est essentielle.

Si vous portez le Vampire ou l'Empathique ​

Vous êtes le soigneur. Maintenez les alliés en vie. Soignez les joueurs blessés. Vous êtes une cible prioritaire pour les Revenants — protégez-vous.

Si vous portez un masque offensif ​

Vous êtes le bras armé des Vivants. Utilisez vos dégâts pour éliminer les Revenants. Ne les gaspillez pas sur des Vivants.
